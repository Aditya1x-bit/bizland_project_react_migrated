# BizLand React Portfolio Website

A multi-page, fully responsive portfolio website built using **ReactJS**, **Bootstrap 5**, and **modular JavaScript**, inspired by the BizLand HTML template from [BootstrapMade](https://bootstrapmade.com/demo/BizLand/).

## 🚀 Features

- ⚛️ ReactJS functional component structure
- 🎨 Bootstrap 5 for modern, responsive UI
- 🖼️ Image carousel using Bootstrap's JS in React
- 📱 Mobile-friendly and cross-browser compatible
- 🌐 Scroll-spy navigation and active link highlighting
- 📩 Newsletter subscription form UI
- 📦 Modular folder structure with reusable components

## 🛠️ Tech Stack

- ReactJS (with Create React App)
- Bootstrap 5
- Bootstrap Icons
- Glightbox (for lightbox gallery)
- Custom CSS & JS

# Notes
This project is inspired by the BizLand HTML template by BootstrapMade.

The original HTML structure has been broken down into React components for reusability and scalability.

Images and placeholder content can be replaced with your own.
